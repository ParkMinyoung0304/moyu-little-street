# 摸鱼小街

> 把班摸了，把钱赚了。

《摸鱼小街》是一款直接在浏览器运行的轻量放置经营小游戏。经营咖啡、烘焙和茶饮店，培养员工、研究菜单、扩张分店，在不同商圈里慢慢把一条小街经营成自己的品牌；闲下来还可以和隔壁老板整点活。

## 主要内容

- 三类店铺：续命咖啡、躺平烘焙、快乐茶水间
- 店铺升级与五星成长，最高 Lv.125
- 定价、产能、菜单熟练度、员工培养与职业成长
- 6 个商圈与不同客群偏好
- 分店项目、街区建设、应用研究与陈设收集
- 隔壁对手、整蛊系统与随机街角事件
- 幸运事件大转轮与特殊金奖事件
- 本地自动存档、离线收益（最多累计 7 天）
- 存档导入 / 导出
- `Esc` 一键切换“工作表”老板模式

## 运行

游戏入口：

```text
src/index.html
```

直接用现代浏览器打开即可游玩，无需安装框架或构建工具。

如果浏览器对本地文件访问有限制，也可以在仓库根目录启动一个简单的 HTTP 服务：

```bash
python -m http.server 8080
```

然后在浏览器中打开对应的 `src/` 页面。

## 存档

游戏默认使用浏览器本地存储保存进度，并每 5 秒自动保存。更换浏览器、设备或移动游戏文件前，建议先使用游戏底部的“导出存档”功能备份。
