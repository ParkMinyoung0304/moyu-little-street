# 摸鱼小街 v3

双击 `index.html`，即可离线游玩。不需要安装、联网或 API Key。

- 3 种店铺自动赚钱。顾客会走向柜台、等待约 2 秒、取到对应商品后离开；顾客动画不重复触发收入结算。
- 经营台可比较产能、客流、实际销量和净利。三种定价改变客流与单件利润；设备不足时加产能，客流不足时换定价、商圈或员工。成本已计入净利，无补货、工资催缴或破产惩罚。
- 6 位员工、3 个驻店席位，免费调岗。员工只需招聘一次，按工作时间自动成长至 10 级，离线也积累经验。12 款菜单分别按真实销量提高熟练度。
- 分店蓝图三选一：便民店、精品店、三店生活馆。只统计启动后符合定价要求的实际订单；完成后自动开业，永久分红及专长加成，继续生成下一站蓝图。每次只筹建一家，下一站等你选择，旧现金不能购买项目进度，不清空任何资产。
- 店铺可逐步进阶至五星，每次开放 25 级设备，最终上限 125 级。进阶需要本店销量、分店数量和资金，原设备保留。
- 三条研究路线各 15 级。前三项解锁基础玩法，后续需要真实销量、分店和累计营业时间；第 4 级至少累计营业 2 小时，第 15 级至少 12 天，均包含离线时间。现金不能绕过这些条件。
- 每 4 小时营业时间轮换一种流行品类，提供 15% 客流加成。分店项目没有终点、限时领取、签到或连续在线要求；后期以经营搭配、员工培养、菜单熟练和扩展版图为目标。
- 24 个对话事件，不限时、不处理也没有损失。
- 可以切换“我的小街 / 看看隔壁”。对手店面随经营状态破损，倒闭后拉下卷帘；随机 75–240 秒后新邻居入驻。转让期间全街随机获得 1.2 / 1.35 / 1.5 / 1.8 倍客流，受设备产能限制，不等于直接乘收入。入驻时播放搬家车、卸货、卷帘开启与剪彩动画。
- 6 种捣乱方式（后 3 种需要研究解锁）、6 种对手人设。每次行动只随机产生一个结果：削弱对手、收入加成、小费、小额破费、短暂减速、帮助对手或扑空。页面可查看每种招数的概率。
- 六段约 10 秒的整活小剧场：优惠券发射车、鸭队行军、吉祥物拎箱离职、配送车卸纸箱、音箱震动与声波、泡泡炮和泡沫。包含进场、执行、老板反应、退场；行动费用、关店奖励和关店后的空铺变化单独结算。经济结果立即保存，切视角或刷新不会重复抽取。
- 12 款招牌产品及联动搭配。点击店铺的“换招牌”免费切换，设备等级保留；精研配方、服务深造和道具保养继续提升后期能力。
- 挂机每分钟获得研发灵感。委托自动结算、自动接下一单、没有截止日期，离线也累计；奖励现金和灵感。
- 完成 3 / 10 / 25 / 50 / 90 单委托解锁不同商圈。6 个商圈有不同客群偏好，免费迁移且保留全部店铺和等级。
- 图鉴持续记录街坊故事、遇见的老板，以及 42 种“招数 × 随机结果”组合。
- 送走第一位对手后，可自由切换 3 种经营风格。
- 默认静音；按 Esc 切换工作表，再按一次返回，经营继续。
- 进度每 5 秒及关键操作后保存；离线正常收益最多累计 7 天。
- 对手不能摧毁店铺。反击最多扣当前现金 3% 且不超过 30 秒正常收入，或降低 10% 收入、持续 20 秒。离线没有反击。
- 反击也可能留下引流广告牌（本店客流 −8%）、叫卖音箱（本店产能 −6%）或宣传气球（本店客流 −6%）。街区最多两件；点击场景道具或提示按钮即可清除，并播放清理动画。不处理则 20 分钟后消失；离线结算忽略道具减益。单店道具客流减益最多 12%、产能减益最多 10%。
- 主动整活翻车损失更小：最多额外扣当前现金 1% 且不超过 10 秒正常收入，或降低 10% 收入、持续 15 秒，减益不叠加。

存档保存在当前浏览器。不同浏览器、不同文件位置和本地预览网址可能使用不同存档。移动文件或清理浏览器前，请点击底部“导出存档”；需要时使用“导入存档”恢复。浏览器禁止本地保存时，页面会提示，仍可游玩并手动导出。

自动兼容 v1 / v2 存档，迁移时保留旧存档备份，不清空现有进度。新增的销量、员工经验与分店项目从本次版本开始积累。DeepSeek 尚未接入；金币只用于游戏。

页面、SVG 道具和动画均在本地编写，没有使用图片生成、外部图片、CDN 或第三方前端库，无需联网。

可选本地预览：在当前目录运行 `python -m http.server 8080 --bind 127.0.0.1`，打开 http://127.0.0.1:8080 。

经济、存档及事件逻辑回归检查：`node qa/check.cjs`。

当前含 37 项回归检查，覆盖定价取舍、进阶条件、离线一致性、旧存档迁移、42 种整活组合的单结果结算、空铺随机范围、持续道具清理和动画不重复结算。浏览器测试页在 `qa/`，使用独立存档键，不能代替 `index.html` 游玩。

开发重建：依次运行 `python qa/upgrade-v3.py`、`python qa/finalize-docs.py`、`python qa/make-preview-v3.py`。v2 基线保存在 `qa/v2-before-v3.html`；用户原有压缩包未改动。
